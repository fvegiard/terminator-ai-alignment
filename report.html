Idle supervisor

The timer uses a monotonic clock and starts only for unfinished work with no pending model, tool, verifier, or accepted delegate. New activity resets it. A first failure queues 0.10; repetition is capped at 0.20. Verified completion earns one point. The component is unit-tested; live runtime adapters remain unimplemented.

Boundaries

Offline non-root inference containers, read-only inputs, no tools for generated text, no live PC access. A constrained host broker performed official Microsoft documentation retrieval. Private reasoning was not captured. The idle behavior has 15 passing unit tests, and the primary container passed 12 boundary checks.
